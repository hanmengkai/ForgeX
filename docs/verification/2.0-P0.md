- PostgreSQL 完整迁移成功；两个仓储实例并发领取只有一个成功；新服务实例恢复交付、审批与已读通知；故障事务回滚。磁盘执行日志重新打开保持原任务，重复回调不重复执行；无法确认中断副作用时阻塞。

## 复跑与接入边界

`npm run p0:sample` 构建后复跑全部 P0 用例并清理隔离业务进程；没有 `FORGEX_TEST_DATABASE_URL` 时 PostgreSQL 用例明确跳过，其他 32 项运行。真实数据库用例仅允许名称以 `_test` 结尾的数据库，并为每次运行创建和删除独立 schema。浏览器验收使用 `npm run build:all` 后执行 `npx playwright test e2e/lifecycle.spec.ts`。

本次样板方案与实现来自受限固定模板。Codex 适配边界使用合成模型响应验证工作树限制和可信 Git 提交绑定，未调用真实模型。通用受控网关客户端已实现，真实 CI/CD 网关及客户测试／生产环境未接入，组织身份源、外部通知和多项目成员授权还需后续验证。当前控制台创建入口使用默认项目，接口支持配置仓库范围。

本次没有执行真实客户生产部署。测试与样板服务已关闭；此前的 `CONTRIBUTING.md` 和营销文档未提交修改保持原样，本轮提交单独保存 P0 代码与文档。

详细配置、故障处置及回退条件见 [2.0 接入说明](../deployment/2.0-P0.md)。
