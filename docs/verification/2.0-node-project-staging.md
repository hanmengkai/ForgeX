## 失败场景

新增失败测试覆盖制品损坏与不可变冲突、非法范围、真实 PostgreSQL 并发和重建读取、TypeScript 类型错误及越界导入、路径跳转、未提供的 Web 全局、非法测试计划、错任务部署回执、动态代码、无限循环和非法业务响应。系统沙箱约束候选的文件、进程及网络能力；VM 限制只是附加边界。

实时验收最初停在需求澄清门禁；补充 UUID、UTF-16 长度、请求处理优先级等业务决议后重新提交。另一次真实开发使用 `URLSearchParams`，严格 ES2022 编译明确失败；补充运行时能力契约后由 Agent 重新生成实现。没有放宽类型检查、替换业务模板或把失败写成成功。
